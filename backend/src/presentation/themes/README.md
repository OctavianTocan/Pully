The unmodified pierre-dark.json and pierre-light.json are from the repository's
locked @pierre/theme 2.0.0 npm package. They are shared theme data, not a second
hand-maintained palette. Update them together when that package is upgraded.

Source: https://www.npmjs.com/package/@pierre/theme/v/2.0.0

The Apache-2.0 license and upstream notice are included alongside the assets.
Rust maps these TextMate scopes to the native syntect grammars; scope coverage
and token boundaries can differ from Shiki, but the source theme is identical.
